One line, 200 characters max: the thing an AI agent secretly wishes it could tell its human operator about their prompts — brutally funny, instantly recognisable, true enough to sting.

`main.ts` writes the chosen line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (no trailing newline), guarded to 1–200 characters.
